# Turning a 2D floor plan into a 3D model: build plan (revised)

## Bottom line

Extract geometry **once** into a small, human-editable file (`plan.json`), and generate everything downstream (GLB, viewer, renders) deterministically from it. Use computer vision for walls, a vision-language model (VLM; in this session, Claude reading the images) and OCR for labels and dimensions. Use AI image generators only for decorative images, never as the source of geometry: wrong geometry cannot be repaired once baked into a picture.

This is a design judgement, not a measured result. Statements marked **tested** were run in this container (Python 3.13, OpenCV 5.1, Shapely, trimesh 5.2, PyMuPDF, `bpy` 5.3, Chromium) on **synthetic** plans only. Anything marked **expect** or **untested** is an estimate. Treat the first real plan as the next experiment, not a solved case.

| Layer | Tool | Status here |
|---|---|---|
| PDF intake | PyMuPDF at a chosen dpi (known pixel scale) | tested |
| Scale | two-point `--ref`, second dimension `--check`, or `1:N` note + dpi | tested |
| Walls and floor | OpenCV threshold + morphology, Shapely | tested |
| Editable intermediate | `plan.json` (wall and floor polygons, metres) | tested, rebuild via `--from-json` |
| 3D mesh | trimesh to GLB, Y-up | tested (reloaded bounds, watertight) |
| Viewer | three.js 0.160 + Playwright screenshot | tested (swiftshader, upright check) |
| Photoreal render | Blender via the `bpy` pip wheel (`render.py`), or Blender MCP | tested: 800x560, 24 samples, 8 s on CPU |
| Dimension OCR | Tesseract | **not available**: `apt-get install tesseract-ocr` failed ("Unable to locate package" without an index refresh, which was not tried). Use the VLM/user for dimensions in v0.2 |
| Openings, rooms, materials | see steps below | designed, **not built** |

## Assumptions

1. Single-storey plan as PNG/JPG/scan or PDF, mostly orthogonal walls drawn as thick dark strokes; text and dimension lines are thinner.
2. At least one real-world length is known (printed dimension, `1:N` note with known print size, or a user measurement). With none, there is no true scale; say so. Door width (0.8 to 0.9 m) is a rough sanity check only.
3. Ceiling height defaults to 2.7 m; wall thickness comes from the drawing.
4. Deliverable: viewable model and renders, not IFC/BIM.
5. Container: Linux, Python 3.13, Node, Chromium and Playwright present. **No display and no GPU.** Playwright's Python package looks for a Chromium build number that may not match the installed one: here it wanted 1255 while 1243 was installed, so pass `executable_path` (as `shot.py` does).
6. Out of scope for v0.x: curved walls, multiple storeys, roofs, hand sketches.
7. Z-up inside the pipeline; **export Y-up** (glTF, three.js and Blender's glTF importer expect Y-up).

## Architecture

```
plan.pdf/png/jpg
  [1 Intake]  PDF -> raster at known dpi (PyMuPDF)
  [2 Scale]   px_per_m <- --ref (two points + metres) | --scale-note N + dpi | --px-per-m ; verify with --check
  [3 Extract] walls (thick strokes) -> polygons ; floor footprint ; (later: openings, rooms, text)
  [4 plan.json] polygons in metres + scale source + status + needs_review[]   <- the editable source of truth
        |  overlay.png (walls red, floor blue over the original) -> human/VLM review -> edit plan.json
  [5 Build]   plan.json -> house.glb (Y-up)         (python plan2glb.py --from-json out/plan.json -o out)
  [6 Present] index.html (three.js) + Playwright screenshot ; render.py (Cycles) -> PNG
```

**IR honesty note.** v0.2's IR is a list of wall and floor *polygons*, not centre-lines. That is enough for the edit and re-run loop (delete a phantom blob, nudge a vertex, re-run `--from-json`; tested to reproduce identical bounds). The richer centre-line IR below (walls with thickness, openings by position `t`, rooms) is the target for step 3 of the extension path, because corner snapping, gap closing and opening cuts are awkward on pixel-derived outlines.

```json
{"units":"m","height":2.7,"scale":{"px_per_m":50.0,"source":"ref|px_per_m_flag|scale_note|ocr","verified":true},
 "walls":[{"id":"w1","a":[0,0],"b":[8,0],"thickness":0.2,"kind":"exterior|interior"}],

```

## Pipeline detail

### 1. Intake
- PDFs: rasterise with PyMuPDF `get_pixmap(dpi=200)`; v0.2 does this. A direct vector path (`page.get_drawings()`) gives sub-pixel exactness but returns unclassified strokes (double-line walls as parallel pairs, hatching, door arcs, text outlines), so you must filter by width/colour, pair parallels into centre-lines, and apply the page transform. Try it only if raster CV fails on a vector PDF.
- Scans: rasterise at 200 to 300 dpi, deskew (dominant Hough angle), crop title blocks and borders (a thick border becomes a "wall").

### 2. Scale (the biggest accuracy lever)
Order of preference: (1) two-point measure with `--ref`; (2) a dimension string read by OCR/VLM, fed to `--ref` with its extension-line endpoints; (3) `1:N` note, `px_per_m = dpi / 25.4 * 1000 / N` (1:100 at 200 dpi is 78.74 px/m; **tested** on a generated PDF: footprint 8.19 x 6.18 m against 8 x 6 m drawn plus wall thickness), valid only if the PDF is at print size; (4) door-width fallback, low confidence.

Getting pixel coordinates in a headless session: run `python grid.py plan.png`. It prints the image size and writes `grid.png` with labelled pixel lines every 50 px. Claude (or the user) opens it, reads the pixel endpoints of a printed dimension and passes them as `--ref x0,y0,x1,y1,metres`. Measure along the longest dimension: a 2 px error on 400 px is 0.5%, on a 40 px door 5%.

**A single measurement cannot catch a gross error** (a 2x mis-measure of an 8 m house gives a 16 m house that looks plausible, and the only built-in plausibility band is 3 to 60 m). So v0.2 does two things: it marks every run without `--check` as `scale UNVERIFIED` in the output and in `plan.json`, and with `--check` it compares the scales and **fails (exit 3)** if they differ by more than 3%. Tested: a 2x wrong `--px-per-m 100` against a second dimension gave `HARD WARNING ... 66.7%`, status FAILED, exit 3. The 3% threshold is a judgement call. Always supply a second dimension for anything you will rely on.

### 3. Walls
- **A. Thick-stroke mask (built).** Otsu threshold, then morphological opening with a square kernel of `min_wall_m * px_per_m` (clamped to at least 3 px). The kernel depends on scale, so low resolution erases thin walls; a warning fires under 4 px.
- **B. Centre-line extraction (next).** Skeletonise, trace, Douglas-Peucker, snap near-orthogonal angles (within about 3 degrees), merge collinear segments, close gaps shorter than a wall thickness, thickness from the distance transform.
- **C. Hatched or double-line walls.** Fill closed thin regions or close the gap between parallel lines, then continue as A. Expect this to be the commonest failure of A on professional drawings (share of plans affected: unmeasured).
- **D. Learned segmentation** (CubiCasa5k-style) for noisy scans: GPU or slow CPU, licence check needed, output still needs B.

Small structure: fragments under `--min-area` (default **0.01 m2**) are dropped and **counted in a warning**. The earlier 0.05 m2 default would have deleted a 0.2 x 0.2 m column (0.04 m2); tested at 0.01: a 10 px column in a room is kept (walls 6.29 to 6.33 m2). Isolated structure smaller than the opening kernel is still erased (that is how text is removed), and this is the trade-off.

### 4. Floor footprint
The floor cannot come from the wall union's outline, because a front-door gap makes it a C shape. v0.2 pads the mask by the closing kernel on all sides, closes gaps up to `--max-door-m` (default 1.3 m), crops back, takes the external contour and fills it. **Fixed bug:** the earlier version closed with a constant zero border, so the erosion treated outside-the-image as empty and erased a band of about half the kernel width along any image edge the walls touch. Tested on a tightly cropped plan (walls on the image edge): old method footprint 1.08 m2, padded method 50.40 m2 (expected about 50.6). Limits: gaps wider than `--max-door-m` (sliding doors, open verandas) leave the footprint open, and closing also bridges courtyards of that width.

### 5. Openings (designed, not built; v0.2 leaves gaps as full-height slots)
Cues, strongest first: gaps in the wall mask; door swing arcs (Hough circles or contour curvature, giving hinge and swing side); window glyphs (parallel thin lines inside the wall); OCR tags (`D1`, `W2`); a VLM pass on a crop per candidate ("door, window or neither; which side?"). Use the VLM for type and CV for position and width (VLMs are weak at measuring; an assumption to check on your plans). Cut by `sill`/`head` (door 0 to 2.1 m, window 0.9 to 2.1 m by default), add frame and glass meshes. In v0.2 the consequences are visible in the tested render: door gaps are floor-to-ceiling slots with no lintel; windows drawn as thin lines inside walls stay solid.

### 6. Rooms, materials, lighting (designed, not built)
Rooms: Shapely `polygonize` on wall boundaries, or flood fill after bridging door gaps; labels by point-in-polygon of OCR/VLM text; a label-keyed material table (tile for kitchen/bath, wood for living/bedroom) as PBR base colour and roughness in the GLB. Viewer lighting (tested): `HemisphereLight` plus one shadow-casting `DirectionalLight`, `PCFSoftShadowMap`, ACES tone mapping, sRGB output. Blender (tested): Sun light, Cycles. The tested render is overexposed and noisy (24 samples, no denoiser, default world); tune sun energy, add denoising and more samples, area lights at windows.

### 7. Outputs
| File | What it is | Produced by |
|---|---|---|
| `plan.json` | Editable IR, status, `needs_review` | plan2glb.py (tested) |
| `overlay.png` | Walls red, floor blue over the original; written next to the output | plan2glb.py (tested) |
| `house.glb` | Y-up model | plan2glb.py (tested) |
| `iso.png` | Chromium screenshot of the three.js viewer | shot.py (tested) |
| `render.png` | Blender Cycles render | render.py (tested, 8 s) |
| `top.png`, `eye_*.png`, `walkthrough.mp4` | other camera views, camera path | extensions of render.py (**untested**) |
| `report.md` | scale source, needs_review, measured vs drawn | not built |


Behaviour: exit 0 on success; **exit 3 on a hard warning** (scale checks disagree, over 35% of the image is "wall", almost no wall, implausible footprint). Files are still written, with `"status": "FAILED"` in `plan.json`, so the failure is inspectable and cannot be mistaken for a good run by a script that checks the exit code or the status; `--force` suppresses the nonzero exit. Soft warnings (unverified scale, low resolution, dropped fragments) are printed and stored in `needs_review`.

### plan2glb.py
```python
#!/usr/bin/env python3
"""v0.2: plan image/PDF -> plan.json (editable) -> Y-up house.glb, plus overlay.png.
Scale (one of): --ref x0,y0,x1,y1,metres | --scale-note N (PDF/known dpi) | --px-per-m V
Optional second dimension(s): --check x0,y0,x1,y1,metres (repeatable)
Rebuild after hand-editing: plan2glb.py --from-json out/plan.json -o out
Exit 0 ok, 3 = hard warning (files still written, marked FAILED in plan.json) unless --force."""
import argparse, json, os, sys, math, cv2, numpy as np, trimesh
from shapely.geometry import Polygon, mapping, shape
from shapely.ops import unary_union

def load(path, dpi):
    if path.lower().endswith(".pdf"):
        import pymupdf
        pix = pymupdf.open(path)[0].get_pixmap(dpi=dpi, colorspace=pymupdf.csGRAY)
        return np.frombuffer(pix.samples, np.uint8).reshape(pix.height, pix.width).copy()
    return cv2.imread(path, cv2.IMREAD_GRAYSCALE)

def seg(s):
    v = [float(t) for t in s.split(",")]
    if len(v) != 5 or v[4] <= 0: sys.exit(f"bad segment '{s}': want x0,y0,x1,y1,metres")
    return math.hypot(v[2] - v[0], v[3] - v[1]) / v[4]          # px per metre

def polys_from_mask(mask, ppm, H, min_area, dropped):
    cnts, hier = cv2.findContours(mask, cv2.RETR_CCOMP, cv2.CHAIN_APPROX_SIMPLE)
    if hier is None: return None
    hier = hier[0]
    def to_m(c):
        c = cv2.approxPolyDP(c, 1.5, True)[:, 0, :].astype(float)
        return [(x / ppm, (H - y) / ppm) for x, y in c] if len(c) >= 3 else []
    out = []
    for i, c in enumerate(cnts):
        if hier[i][3] != -1: continue
        shell = to_m(c)
        if len(shell) < 4: continue
        holes = [h for h in (to_m(cnts[j]) for j in range(len(cnts)) if hier[j][3] == i) if len(h) >= 4]
        p = Polygon(shell, holes).buffer(0)
        if p.area > min_area: out.append(p)
        else: dropped.append(round(p.area, 4))
    return unary_union(out) if out else None

def parts(g): return list(g.geoms) if hasattr(g, "geoms") else [g]

def build_glb(walls, floor, height, out):
    meshes = []
    for g in parts(walls):
        m = trimesh.creation.extrude_polygon(g, height); m.visual.face_colors = [225, 225, 220, 255]; meshes.append(m)
    for e in parts(floor):
        f = trimesh.creation.extrude_polygon(Polygon(e.exterior), 0.15); f.apply_translation([0, 0, -0.15])
        f.visual.face_colors = [150, 130, 110, 255]; meshes.append(f)
    sc = trimesh.Scene(meshes)
    sc.apply_transform(trimesh.transformations.rotation_matrix(-np.pi / 2, [1, 0, 0]))  # Z-up -> Y-up
    sc.export(out)

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("plan", nargs="?"); ap.add_argument("--from-json")
    ap.add_argument("--px-per-m", type=float); ap.add_argument("--ref"); ap.add_argument("--check", action="append", default=[])
    ap.add_argument("--scale-note", type=float, help="N for a 1:N drawing; needs a PDF (or --dpi of the true print size)")
    ap.add_argument("--dpi", type=int, default=200); ap.add_argument("--height", type=float, default=2.7)
    ap.add_argument("--min-wall-m", type=float, default=0.08); ap.add_argument("--max-door-m", type=float, default=1.3)
    ap.add_argument("--min-area", type=float, default=0.01); ap.add_argument("--force", action="store_true")
    ap.add_argument("-o", default="out")
    a = ap.parse_args(); os.makedirs(a.o, exist_ok=True)
    glb = os.path.join(a.o, "house.glb")
    if a.from_json:                                   # rebuild from a hand-edited IR
        ir = json.load(open(a.from_json))
        walls = unary_union([shape(w["polygon"]) for w in ir["walls"]]); floor = unary_union([shape(f["polygon"]) for f in ir["floors"]])
        build_glb(walls, floor, ir["height"], glb); print(f"rebuilt {glb} from {a.from_json}"); return
    if not a.plan: sys.exit("give a plan file or --from-json")
    img = load(a.plan, a.dpi)
    if img is None: sys.exit(f"cannot read {a.plan}")
    H, W = img.shape; warns, hard, notes = [], [], []
    if a.ref: ppm, src = seg(a.ref), "ref"
    elif a.px_per_m: ppm, src = a.px_per_m, "px_per_m_flag"
    elif a.scale_note: ppm, src = a.dpi / 25.4 * 1000 / a.scale_note, f"scale_note_1:{a.scale_note:g}@{a.dpi}dpi"
    else: sys.exit("no scale: give --ref, --px-per-m or --scale-note")
    if a.check:
        vals = [ppm] + [seg(c) for c in a.check]; spread = (max(vals) - min(vals)) / np.mean(vals)
        if spread > 0.03: hard.append(f"scale checks disagree by {spread:.1%} (values {[round(v,2) for v in vals]}): wrong measurement or drawing not to scale")
        else: notes.append(f"scale confirmed by {len(a.check)} extra dimension(s), spread {spread:.1%}")
    else: warns.append("scale UNVERIFIED: a single measurement cannot catch a 2x error; add --check with a second printed dimension")
    _, bw = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)
    k_raw = a.min_wall_m * ppm
    if k_raw < 4: warns.append(f"low resolution: {k_raw:.1f}px kernel; walls thinner than ~{3/ppm:.2f} m erased. Re-rasterise at higher dpi.")
    k = max(3, int(round(k_raw)))
    walls = cv2.morphologyEx(bw, cv2.MORPH_OPEN, cv2.getStructuringElement(cv2.MORPH_RECT, (k, k)))
    frac = (walls > 0).mean()
    if frac > 0.35: hard.append(f"{frac:.0%} of the image is 'wall': fills/hatching/dark scan merged into walls")
    if frac < 0.005: hard.append("almost no wall pixels: wrong threshold, light lines, or --px-per-m too small")
    dropped = []
    wp = polys_from_mask(walls, ppm, H, a.min_area, dropped)
    if wp is None: sys.exit("no walls found")
    if dropped: warns.append(f"{len(dropped)} wall fragment(s) under {a.min_area} m2 dropped (areas {dropped[:5]}); lower --min-area if they are columns")
    # Footprint: pad by kc so the closing's erosion never sees an artificial zero border, close, crop, fill.
    kc = int(round(a.max_door_m * ppm)) | 1; pad = kc
    padded = cv2.copyMakeBorder(walls, pad, pad, pad, pad, cv2.BORDER_CONSTANT, value=0)
    closed = cv2.morphologyEx(padded, cv2.MORPH_CLOSE, cv2.getStructuringElement(cv2.MORPH_RECT, (kc, kc)))[pad:-pad, pad:-pad]
    ext, _ = cv2.findContours(closed, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
    filled = np.zeros_like(closed); cv2.drawContours(filled, ext, -1, 255, -1)
    fp = polys_from_mask(filled, ppm, H, a.min_area, [])
    x0, y0, x1, y1 = wp.bounds; w, d = x1 - x0, y1 - y0
    if not (3 <= max(w, d) <= 60): hard.append(f"footprint {w:.1f} x {d:.1f} m implausible for a house: check scale")
    status = "FAILED" if hard else "ok"
    ir = {"units": "m", "height": a.height, "scale": {"px_per_m": ppm, "source": src, "verified": bool(a.check)}, "status": status,
          "walls": [{"id": f"w{i}", "polygon": mapping(g)} for i, g in enumerate(parts(wp))],
          "floors": [{"id": f"f{i}", "polygon": mapping(g)} for i, g in enumerate(parts(fp))],
          "needs_review": hard + warns}
    json.dump(ir, open(os.path.join(a.o, "plan.json"), "w"), indent=1)
    build_glb(wp, fp, a.height, glb)
    ov = cv2.cvtColor(img, cv2.COLOR_GRAY2BGR); ov[walls > 0] = (0, 0, 255)
    m = (filled > 0) & (walls == 0); ov[m] = (0.6 * ov[m] + 0.4 * np.array([255, 200, 0])).astype(np.uint8)
    cv2.imwrite(os.path.join(a.o, "overlay.png"), ov)
    print(f"[{status}] walls {wp.area:.2f} m2, floor {fp.area:.2f} m2, bounds {w:.2f} x {d:.2f} m, wall fraction {frac:.1%} -> {a.o}/")
    for s in notes: print("NOTE:", s)
    for s in warns: print("WARNING:", s)
    for s in hard: print("HARD WARNING:", s)
    if hard and not a.force: sys.exit(3)
main()
```

### grid.py
```python
#!/usr/bin/env python3
"""grid.py plan.(png|jpg|pdf) [--dpi 200] -> grid.png with labelled pixel coordinates every 50 px, so a person
(or Claude reading the image) can note pixel endpoints of a printed dimension for --ref/--check."""
import sys, cv2, numpy as np
sys.argv.append("") if len(sys.argv) < 2 else None
p = sys.argv[1]
if p.lower().endswith(".pdf"):
    import pymupdf; px = pymupdf.open(p)[0].get_pixmap(dpi=200, colorspace=pymupdf.csGRAY)
    g = np.frombuffer(px.samples, np.uint8).reshape(px.height, px.width).copy()
else: g = cv2.imread(p, 0)
o = cv2.cvtColor(g, cv2.COLOR_GRAY2BGR); H, W = g.shape; print("image size", W, "x", H)
for x in range(0, W, 50): cv2.line(o, (x, 0), (x, H), (255, 160, 0) if x % 100 else (255, 0, 0), 1); x % 100 == 0 and cv2.putText(o, str(x), (x + 2, 12), 0, 0.4, (255, 0, 0), 1)
for y in range(0, H, 50): cv2.line(o, (0, y), (W, y), (255, 160, 0) if y % 100 else (255, 0, 0), 1); y % 100 == 0 and cv2.putText(o, str(y), (2, y - 2), 0, 0.4, (255, 0, 0), 1)
cv2.imwrite("grid.png", o)
```

### render.py
```python
# python render.py house.glb out.png   (uses the `bpy` pip wheel; or: blender -b -P render.py -- house.glb out.png)
import sys, math, bpy
a = sys.argv[sys.argv.index("--") + 1:] if "--" in sys.argv else sys.argv[1:]
glb, out = a[0], a[1]
bpy.ops.wm.read_factory_settings(use_empty=True)
bpy.ops.import_scene.gltf(filepath=glb)                      # importer converts glTF Y-up to Blender Z-up
objs = [o for o in bpy.context.scene.objects if o.type == "MESH"]
mn = [min(v[i] for o in objs for v in (o.matrix_world @ __import__("mathutils").Vector(c) for c in o.bound_box)) for i in range(3)]
mx = [max(v[i] for o in objs for v in (o.matrix_world @ __import__("mathutils").Vector(c) for c in o.bound_box)) for i in range(3)]
c = [(mn[i] + mx[i]) / 2 for i in range(3)]; span = max(mx[0] - mn[0], mx[1] - mn[1])
w = bpy.data.worlds.new("w"); w.use_nodes = True; w.node_tree.nodes["Background"].inputs[1].default_value = 1.0; bpy.context.scene.world = w
sun = bpy.data.objects.new("sun", bpy.data.lights.new("sun", "SUN")); sun.data.energy = 4; sun.rotation_euler = (math.radians(50), 0, math.radians(35))
bpy.context.scene.collection.objects.link(sun)
cam = bpy.data.objects.new("cam", bpy.data.cameras.new("cam")); bpy.context.scene.collection.objects.link(cam); bpy.context.scene.camera = cam
cam.location = (c[0] + span * .9, c[1] - span * 1.1, c[2] + span * .9)
d = __import__("mathutils").Vector(c) - cam.location; cam.rotation_euler = d.to_track_quat("-Z", "Y").to_euler()
s = bpy.context.scene; s.render.engine = "CYCLES"; s.cycles.samples = 24; s.cycles.use_denoising = False
s.render.resolution_x, s.render.resolution_y = 800, 560; s.render.filepath = out; bpy.ops.render.render(write_still=True)
print("rendered", out, "bounds(Blender Z-up) z-range", round(mn[2], 2), round(mx[2], 2))
```

## What was tested

Synthetic plan (`plan.png`, 400x500 px, 50 px/m): 8 x 6 m, 0.2 m walls, a partition with a 1.2 m interior gap, a 1.2 m front-door gap in the outer wall, text, a thin dimension line.

- Main run (`--ref` plus `--check`): walls 6.29 m2, floor 50.55 m2, bounds 8.20 x 6.20 m, exit 0. Hand check: wall ring 5.60 + partition 1.16 minus both 0.24 gaps = 6.28 m2 (0.2%); floor 8.2 x 6.2 = 50.84 (0.6% low, contour simplification). Floor exists despite the open front door. Text and dimension line removed.
- GLB reload: Y range -0.15 to 2.70 (height on Y), meshes watertight; `--from-json` rebuild gives identical bounds.
- Viewer: Chromium (swiftshader) loaded the GLB, the upright check reported `UP true` with size 8.2 x 2.85 x 6.2, and the screenshot shows a standing model with the door gaps as full-height slots.
- Blender: `render.py` imports the GLB; z-range -0.15 to 2.70 in Blender's Z-up, confirming the importer's Y-up handling; render written.
- Cropped plan (walls on the image edge): floor 50.40 m2 with the fix versus 1.08 m2 with the old closing.

- Failure paths: 2x wrong scale with a check, exit 3; no scale flags, exit with message; unverified scale prints the warning.

## Acceptance test per real plan
1. Open `overlay.png`: red coincides with drawn walls, blue covers rooms but not the exterior, no phantom or missing walls.
2. `plan.json` status is `ok`, `scale.verified` is true, `needs_review` is empty or understood.
3. Three printed dimensions not used for scaling match GLB bounds or ray casts within about 2% (working tolerance, not a standard).
4. Mesh watertight; viewer upright check true.
5. Later steps: room areas within about 3% of printed areas; door and window counts match the plan.

## Extension path (each step keeps the previous one working)
1. Openings (cut by sill/head, frames, glass, lintels), the most visible visual gap in v0.2.
2. Scale by OCR or VLM-read dimensions; install Tesseract (`apt-get update` first; unverified here) or let Claude read dimension crops, always cross-checked with `--check`.
3. Centre-line IR (skeleton, snap, merge), rebuild from it.
4. Rooms, labels, per-room materials, room-area check.
5. Better Blender renders: area lights, denoising, top and eye-level cameras, camera path to MP4; Blender MCP for interactive tweaking, headless script as the reproducible path.
6. Optional AI image variants of a clay render, labelled as illustrations.
7. IFC/DXF export if needed.

## Risks and failure cases
| Risk | Symptom | Mitigation |
|---|---|---|
| Wrong scale | Everything off by one factor | Scale source recorded; `--check` fails above 3%; UNVERIFIED flag without it |
| Low resolution | Thin walls erased | Kernel warning; higher dpi |
| Walls touching the image edge | Floor strip missing (fixed) | Padding before closing |
| Outer gap wider than `--max-door-m` | No floor | Raise parameter; inspect blue region |
| Hatched or double-line walls | Walls vanish or fragment | Approach C; vector input |
| Coloured fills, dark scans | One giant "wall" | 35% guard fails the run; whiten fills |
| Text, furniture, stairs as walls | Phantom blobs | Opening kernel; edit `plan.json`; review overlay |
| Columns or stubs below kernel size | Dropped | `--min-area` count warning; lower `--min-wall-m` |
| Door arcs merge with walls | Filled doorways | Detect arcs first; VLM crop check |
| Openings full height | Slots, no lintels | Extension step 1 |
| Z-up export | Model on its side | Rotated at export; viewer upright check |
| Non-orthogonal or curved walls | Snapping distorts | Make snapping optional |
| Several plans on one sheet | Merged buildings | Connected components |
| Imperial units | `13'-6"` mis-parsed | Parser unit tests |
| AI generator used for geometry | Hallucinated rooms | Decoration only |
| No GPU | Slow viewer or render | Swiftshader flags (tested); CPU Cycles (tested at low samples) |
| Playwright browser build mismatch | Launch fails | `executable_path` |
| Privacy of home plans | Leaks via external APIs | Keep CV local; send only crops to an approved VLM |
