ATTACK 1: CONCEDE. Erode-and-dilate only suits solid-fill walls, and double-line and hatched walls are the common CAD convention. The revision adds a wall-style detector and a method for each style: pair parallel strokes for vector PDFs, and close the gap between line pairs for rasters.
ATTACK 2: CONCEDE. trimesh extrudes along +Z and exports without rotating to glTF Y-up. The revision builds in a Z-up plan frame, applies one stated rotation (plan x to x, plan y to -z, height to y) before export, and adds a test that the bounding box height equals the wall height.
ATTACK 3: CONCEDE. Centreline polygons overstate net room area, so the 3.0 x 4.0 m example is right (about 6.8 percent over). The revision derives rooms from the wall-footprint complement, which is the net floor, and defines the area check as net versus printed net, with the tolerance stated.
ATTACK 4: CONCEDE. The old step was one sentence and the fallback order was circular. The revision gives an association algorithm (OCR at 4 rotations, nearest dimension line in the text's perpendicular direction, then a ratio test), makes manual two-point scale the version 1 default so nothing depends on door detection, and makes OCR scale a version 2 addition.
ATTACK 5: CONCEDE. file:// blocks fetch for GLB. The revision serves the folder with python -m http.server, vendors three.js locally (npm pack, no CDN), uses an import map, and has shot.py start the server itself.
ATTACK 6: CONCEDE. The install block was incomplete. The revision adds a preflight that checks for tesseract, blender and root, and gives an install path or a skip for each. The version 1 path is made independent of both.
ATTACK 7: CONCEDE. The estimates were optimistic and the done criterion was vague. The revision gives realistic times, names the test plans (a synthetic generated plan plus a public CubiCasa5k-style sample, or the user's own), and sets numeric pass thresholds.
