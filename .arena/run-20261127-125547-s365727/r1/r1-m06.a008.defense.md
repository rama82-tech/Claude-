ATTACK 1: CONCEDE. v1 did take wall coordinates from the vision reader with a report-only check. Fixed: v1 now takes geometry from the CV reader (B) and uses the vision reader (A) only for meaning (wall vs furniture, door vs window, room names). I also dropped the unverified assumption that a vision API exists: in a Claude Code session Claude reads the image itself and writes the JSON.
ATTACK 2: CONCEDE. The match metric was undefined and the tolerance was too tight. Fixed: matching is now defined (angle under 5 degrees, perpendicular distance in mm from A's endpoints to B's centre-line under 2 wall thicknesses, overlap over 50 percent). A's coordinates are snapped onto B, not rejected. Unconfirmed walls are built in a red "draft" mode instead of vanishing, so the model is never near-empty.
ATTACK 3: CONCEDE. The round trip only proves the build matches plan.json, not that plan.json matches the drawing. Fixed: it is renamed a build check and no longer sold as the safeguard for extraction errors. A separate human overlay of the model on the source image does that job. The IoU and 100 mm pair is replaced by a one-sided distance test in mm, scaled to wall thickness.
ATTACK 4: CONCEDE. I checked this container: no Blender, no OpenCV, no PyMuPDF, no Tesseract; trimesh, shapely and Node are installed. So v1 is now rebuilt on trimesh + shapely (GLB) with a three.js viewer rendered by Playwright. Blender becomes the optional v2 for quality renders, with a stated install check and fallback.
ATTACK 5: CONCEDE. Bare millimetre numbers are the normal metric case. Fixed: a plan-wide unit via --unit or the title block, or inferred from magnitude and echoed back for confirmation. Only genuinely ambiguous small numbers are refused.
ATTACK 6: CONCEDE. Vector PDFs still need wall classification and double-line to centre-line conversion. Fixed: the fast path is described with an actual method (PyMuPDF get_drawings, filter by stroke width and colour, pair parallel lines), scored 4 not 5, and no longer claimed to skip CV classification.
ATTACK 7: CONCEDE. Deskew and the 12 degree reject contradicted each other, and 1500 px was arbitrary. Fixed: deskew up to 15 degrees is automatic; reject only for perspective or over 20 degrees; resolution is WARN under 1500 px and REJECT under 600 px, with listing images at 800 to 1200 px expected to work at lower accuracy. The test set is rewritten to match.
