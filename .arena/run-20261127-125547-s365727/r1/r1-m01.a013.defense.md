ATTACK 1: CONCEDE. In shapely, cap_style=2 is flat, so an L corner loses a t/2 square and T-junctions end flush. Fixed: build.py now extends each end by t/2 and uses cap_style=3 (square); the acceptance test compares against the outer wall faces.
ATTACK 2: CONCEDE. Erosion with a kernel equal to the wall width is wrong. Replaced with a morphological opening using a kernel between the thin-line width and the wall width, picked from a stroke-width histogram (distance transform), run in two passes so 0.1 m partitions and 0.4 m outer walls are both kept. Thickness is read per wall from the distance transform.
ATTACK 3: CONCEDE. EEVEE needs OpenGL and is unreliable without a GPU. Cycles on CPU is now the only render engine promised, with timings given as estimates to be measured. Added a Blender install path (pip bpy wheel, else the official tarball) and a rule that Blender stays optional and untested until a smoke test passes.
ATTACK 4: CONCEDE. All three sub-points are right. Added scikit-image to the install line (skeletonize), a local http.server for the GLB, and Chromium software-WebGL flags with a blank-canvas check. Also added a fallback that renders the preview with trimesh/matplotlib if WebGL fails.
ATTACK 5: CONCEDE. Ceiling height is not on a plan, so that check was meaningless, and the room range rejected valid small and large rooms. The hard check is now door-width only (0.6 to 1.2 m, majority of doors). Room size is a warning, not a stop, and the user can override with an explicit confirm.
ATTACK 6: CONCEDE. Added an explicit scale step: the user names two points or a wall id for the typed length, px-per-metre is applied, and y is flipped (image y down to world Y up) with a documented axis mapping. Added an asymmetric-marker acceptance test (an L-shaped plan) that catches mirroring, since the overlay alone cannot.
ATTACK 7: CONCEDE. Multi-storey is now designed: a shared origin from a common anchor (stair or column pair, or the user's two clicks per page), per-floor scale must match within 3 percent, a storey height setting, and stair openings cut in the slab above. Marked as a version 3 feature, not version 1.
