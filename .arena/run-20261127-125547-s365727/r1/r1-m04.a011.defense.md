ATTACK 1: CONCEDE. The plan.json format was never defined and v1 had no code. The revision gives a full schema (centreline walls in metres, openings that point to a wall by id and a distance along it, openings cut in 2D) and a working plan_to_3d.py. I ran that script on a two-room test plan and it exported a GLB.
ATTACK 2: CONCEDE. A single-dimension plan is legitimate, so a mandatory second dimension contradicts my own assumptions. Scale now has three states (verified, single-source, assumed). A plan with one dimension builds and is stamped UNVERIFIED. Only a real disagreement between two measurements blocks the build.
ATTACK 3: CONCEDE. Centreline sizes exceed printed clear sizes by about one wall thickness, which would give a false alarm on a correct model. The check now compares the room polygon minus the wall bodies (clear size) against the printed value, and records whether each printed number is clear or centreline. The script includes clear_size(). On the test plan it returns 2.35 m for a 2.5 m centreline bay, as expected.
ATTACK 4: CONCEDE. file:// blocks the GLB fetch and headless Chromium without a GPU needs software-GL flags. The revision names three fixes: serve over `python -m http.server`, or embed the GLB as base64; vendor a pinned three.js; launch Chromium with swiftshader flags. It defines the camera presets in code and adds a matplotlib top-down fallback that needs no WebGL. The Chromium flags are stated as things to test first, not as verified.
ATTACK 5: CONCEDE, PARTLY. The install claim was unverified, and that was wrong. I tried `pip download bpy` in this container (Python 3.13) and it found no matching distribution. Blender is now optional, with an explicit 5-minute probe, a tarball route, and the fallback that v1 and v2 produce all required outputs without it. Cycles on CPU gets a realistic cost note. The GLB-has-no-lights point is conceded: lights live in the viewer or the Blender script. I rebut only the implication that Blender is on the critical path, because it never was in v1.
ATTACK 6: CONCEDE. The y-flip and the axis conversion were unspecified. The plan coordinate frame is now metres, X east, Y north, Z up, with the image-row flip done once at ingest. The Z-up to Y-up rotation is explicit in code. The origin is shifted so the plan's minimum corner is (0,0), which removes the unreachable "lower-left corner" claim.
