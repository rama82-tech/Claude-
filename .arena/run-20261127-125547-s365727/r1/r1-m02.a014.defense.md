ATTACK 1: CONCEDE. In v1 there are no rooms or names, so `--known "Living room width=..."` cannot resolve. Fixed: v1 takes `--scale-line "x1,y1,x2,y2=14'-6\""` (two pixel points read off the overlay), and the room-based form is moved to v1.3.
ATTACK 2: CONCEDE. file:// blocks fetch and module loading, the viewer path to the GLB was unspecified, and the CDN import needs outbound access. Fixed: three.js is vendored from `npm install three@0.160.0`, the viewer sits next to `house.glb`, and it is served and tested through `python -m http.server`.
ATTACK 3: CONCEDE. A unioned mesh cannot be re-heightened, and the "outward normal" test is undefined for interior walls. Fixed: no union (walls stay separate objects). The cutaway is a second build pass with a defined rule (every wall 1.2 m, exterior walls on the far side of the view direction stay full height) and the opening cutters are clipped to the new height.
ATTACK 4: CONCEDE. A centreline polygon includes half a wall on each side, so small rooms are over-counted by roughly 10%. Fixed: room polygons are the centreline polygons minus the union of wall footprints (equivalent to an inset by half the thickness). The thresholds are one rule: warn above 3%, fail above 8%.
ATTACK 5: CONCEDE. The "5-9 px" kernel was wrong by 2 to 5x at common scales, and the thickness was needed before it was measured. Fixed: a bootstrap that takes the run-length histogram of dark pixels, plus a table of wall thickness in pixels per drawing scale at 300 DPI.
ATTACK 6: CONCEDE. The fallback had no source, no install step, and an unsourced accuracy figure. Fixed: the unsourced "85-95%" claim is removed, and CubiCasa5K is moved to an optional v2 with the repo name, the manual weight download, the likelihood that the proxy blocks it, and the fact that it gives no metric scale. Nothing in v1 depends on it.
ATTACK 7: CONCEDE. glTF cannot carry procedural nodes, and `swing` was unused. Fixed: the GLB uses flat PBR colours in v1. In v1.3 floor textures are PNGs generated with numpy and applied with physical-size UVs so they export. A door leaf mesh is now built from `swing` (a 0.04 m slab hinged open to 90 degrees, or closed via a flag).
