ATTACK 2: CONCEDE. Printed dimensions are face-to-face or overall, so centreline checks gave false flags. Each dimension now carries `basis` per end (inside/outside/centre) and the wall pair; the checker adds or subtracts half-thickness. I ran it: 7.8 inside and 8.2 outside pass, 8.0 inside is flagged. v1 only reports residuals and never auto-shifts walls.
ATTACK 3: CONCEDE. The MultiPolygon comment was false and the 3x-deep cut could notch a perpendicular wall. The code now extrudes each polygon in a loop, cuts only wall thickness plus 2 cm, and rejects any opening whose footprint touches another wall. I ran it on a detached wall and on a door 2 cm from a T-junction, and the second was rejected with a message.
ATTACK 4: CONCEDE. The install line was wrong. It now uses opencv-contrib-python-headless (not both OpenCV packages), mapbox-earcut for triangulation, and a smoke test. OCR is explicitly deferred out of v1, with the tesseract and easyocr costs stated.
ATTACK 5: CONCEDE. The build code now skips virtual walls for extrusion but keeps them for polygonize, splits ext and int wall meshes by `kind`, maps polygons to labels through each room's `seed` point, and builds floors as room polygon minus wall footprint. Unlabelled loops produce a warning and a grey floor. I ran this on a plan with a virtual wall and a detached wall.
