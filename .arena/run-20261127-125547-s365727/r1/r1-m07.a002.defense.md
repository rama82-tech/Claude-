ATTACK 1: CONCEDE. The plan never said who reads the image. Revised: in a Claude Code session, Claude reads the image directly with its image-viewing Read tool and writes plan.json, with no key needed. A scripted API call is an optional mode that needs ANTHROPIC_API_KEY and is stated as such. The hand-written fallback is now a separate build-only test.
ATTACK 2: CONCEDE. The schema example was wrong (centreline rectangle used as the room, 20.8 m2 against a true 19.0 m2). Revised: every printed dimension is tagged face-to-face or outer-face or centreline, and the pixel endpoints are taken on those faces. Walls are stored as centrelines, and rooms are derived from the wall faces. The area check compares the derived interior area, and the schema example is corrected. The acceptance test is defined on interior face dimensions.
ATTACK 3: CONCEDE. model-viewer has no orthographic camera, and the GPU, CDN and file:// issues were real. Revised: previews use three.js vendored locally (npm install), an OrthographicCamera, a local http.server, and Chromium launched with software-WebGL flags. A pure-Python matplotlib top-down render is the no-WebGL fallback, and a blank-image check is added.
ATTACK 4: CONCEDE. Revised scale: for vector PDFs the dimension strings and their positions come from the pymupdf text layer, which is exact. For raster images they come from tesseract OCR cross-checked against the model reading. Scale is a least-squares fit over three or more dimensions, with a 1% tolerance and a hard stop on disagreement. Printed room sizes give an independent check. The overlay now draws the dimension endpoints too.
ATTACK 5: CONCEDE in part. Revised: the closed-loop check is a warning only, and walls are tagged exterior, interior, partial or half-height. Snapping tolerance is the smaller of 5 cm and a third of the thinnest wall. Axis snapping applies only within 3 degrees and has a flag to turn it off. Walls at other angles are kept as drawn.
ATTACK 6: CONCEDE. Revised: rooms are no longer an independent model output. Rooms are derived with shapely polygonize on the wall network (with door gaps bridged), and the model's room labels are points assigned to the derived polygons. Unlabelled or label-less polygons are flagged. Floor slab is z=-0.1 to 0 and walls run from 0, so they no longer overlap. The output is stated: separate watertight bodies in one scene, each checked with is_watertight.
ATTACK 7: CONCEDE. Revised: make_test_plan.py draws a known 2-bedroom plan with an entrance door and printed face dimensions, and the acceptance test is defined on those interior face dimensions with exact expected values.
